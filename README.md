# 建木Core (jianmu-core)
离散拓扑自洽校准引擎
全域建木锚点校准底层Python工具库

## 项目简介
建木Core 轻量无第三方依赖，纯标准库实现，提供时序物理修正、文本熵校验、多维度事实校准、空间拓扑映射、流量防御、共振时序传输、双曲几何演化全套自洽校验能力。
无需大模型、开箱即用，适配科研仿真、文本置信校验、时序通道模拟、拓扑空间映射场景。

## 环境要求
Python >= 3.8
